X Bridge Privacy Policy

Last updated: August 30, 2026

Overview

X Bridge is a personal automation bridge designed to connect user-authorized services with local automation workflows.

Google User Data

X Bridge accesses Google account data only after the user explicitly authorizes access through Google OAuth.

Depending on the permissions granted by the user, X Bridge may use Google services such as Gmail to send messages requested by the user and Google Drive for files used by authorized automation workflows.

How Data Is Used

Google user data is used only to provide functionality explicitly requested or configured by the user.

X Bridge does not sell Google user data and does not use Google user data for advertising.

Data Sharing

X Bridge does not intentionally share Google user data with third parties except when necessary to perform an action explicitly requested by the user.

Security

OAuth authorization is used to access supported Google services. Users remain in control of the permissions granted to X Bridge.

Revoking Access

Users can revoke X Bridge access at any time from their Google Account security and third-party access settings.
